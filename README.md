# shopease-app
 ShopEase is a modern React Native e-commerce mobile app built with Expo. It features a dark-themed UI with product browsing, real-time search, category filters, product detail pages with size selection, a shopping cart, and a wishlist all built using only React Native core components and hooks. No external UI libraries needed.

# ShopEase — React Native E-Commerce App

## Getting Started

### Prerequisites
- Node.js (v18+)
- Expo CLI

### Installation

```bash
git clone https://github.com/YOUR_USERNAME/shopease-app.git
cd shopease-app
npm install
npx expo start
```

Scan the QR code with **Expo Go** app on your phone.
